# Что это такое

Этот проект помогает развернуть небольшой BOINC-кластер и запустить на нём эксперимент.

## Идея простыми словами

Обычная программа обычно запускается на одной машине. BOINC позволяет разделить работу на много маленьких задач и раздать их разным компьютерам.

В терминах BOINC:

- **project** — вычислительный проект на сервере;
- **server** — машина, которая хранит задачи, клиентов и результаты;
- **client** — машина, которая забирает задачи, считает и возвращает результат;
- **workunit** — маленькая единица работы;
- **result** — конкретная попытка выполнить workunit на клиенте;
- **host** — зарегистрированный клиентский узел.

## Что делает этот репозиторий

Репозиторий автоматизирует полный цикл:

1. создаёт конфигурацию кластера;
2. поднимает BOINC server и MariaDB в Docker;
3. создаёт BOINC account;
4. разворачивает BOINC clients на вычислительных узлах через Ansible;
5. создаёт много маленьких задач;
6. просит клиентов забрать задачи;
7. показывает статус выполнения.

## Зачем здесь Docker и Ansible

Docker используется, чтобы сервер и клиенты запускались воспроизводимо, без ручной настройки BOINC на каждой машине.

Ansible используется, чтобы с управляющей машины установить и запустить BOINC client-контейнеры на всех вычислительных узлах.
